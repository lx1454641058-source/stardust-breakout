# Stardust Breakout

星尘突围是一款单文件 HTML 地牢射击游戏原型，包含角色成长、武器与元素融合、波次战斗和设置面板等交互。

## 在线预览

将仓库发布为 GitHub Pages 后，打开 Pages 地址即可体验。入口文件为 `index.html`。

## 本地运行

项目没有构建步骤，可直接打开 `index.html`，或运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件说明

- `index.html`：游戏原型主体
- `*-atlas.png`：角色、武器和元素融合素材图集
- `Stardust-Breakout-demo.zip`：原始演示压缩包

本仓库未附加新的第三方代码或运行时依赖；项目原始授权信息未在源文件中声明。
